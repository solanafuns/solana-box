🚀 Solana Box

A Docker container for Solana development with a web-based VS Code environment

Overview

Solana Box is a pre-configured development container that includes all the tools you need to build Solana applications. Get started with Solana development in minutes, no complex setup required!

✨ What's Included

🔧 Solana CLI

Latest Solana tools and utilities pre-installed and ready to use

🦀 Rust Toolchain

Rust 1.89.0 for Solana program development

💻 Code Server

VS Code in your browser with Python and Rust extensions

🤖 Claude Code Router

AI code assistant router with OpenRouter support

🛠️ Development Tools

Build essentials, pkg-config, protobuf compiler, and more

🔑 Pre-configured Wallet

Default Solana wallet keypair included for quick testing

🚀 Quick Start

Run the container:

docker run -d --rm -p 8080:8080 --platform=linux/amd64 -v /tmp:/app ghcr.io/solanafuns/solana-box:latest

Then open your browser and navigate to:

http://localhost:8080

You'll see VS Code running in your browser, ready for Solana development! 🎉

📋 Usage Examples

Basic Run

docker run -d --rm -p 8080:8080 --platform=linux/amd64 ghcr.io/solanafuns/solana-box:latest

With Volume Mounting

docker run -d --rm \
  -p 8080:8080 \
  --platform=linux/amd64 \
  -v $(pwd):/workspace \
  ghcr.io/solanafuns/solana-box:latest

Custom Port

docker run -d --rm -p 3000:8080 --platform=linux/amd64 ghcr.io/solanafuns/solana-box:latest

Access at http://localhost:3000

🔌 Exposed Ports

8080 Code Server (VS Code web interface) 3456 Claude Code Router 443 HTTPS 3000 Development port 3001 Development port 80 HTTP

⚙️ Configuration

Claude Code Router

Configure the AI code assistant router by copying and editing the example configuration:

cp example.json ~/.claude-code-router/config.json
vim ~/.claude-code-router/config.json
claude-code-router start

Solana MCP Server

Add the Solana Model Context Protocol server for enhanced development capabilities:

claude mcp add --transport http solana-mcp-server https://mcp.solana.com/mcp

🏗️ Build from Source

docker build -t solana-box:latest .
docker run -d --rm -p 8080:8080 solana-box:latest
